Every page is different. All of it is EVARA-LUX.

One set of locked foundations, nine atmospheres. Choose an aura and this whole page becomes that environment, using the same tokens the product will ship.

    Same DNA, different personality

    The rule that keeps this from turning into chaos: foundations are locked, and personality is a small set of named dials.

    Locked for every page

    • Spacing on a 4px grid and a 1.25 modular type scale
    • Focus ring, 44px touch targets, contrast floors
    • Navigation logic and component behaviour
    • Reduced motion, performance budgets, security

    Allowed to change with the aura

    • Palette, lighting, and how much atmosphere fills the space
    • Motion tempo, from slow and weighty to kinetic
    • Density, depth, typographic drama, image treatment
    • Composition: a separate layout for compact and expanded screens

    Accessible in every aura, checked by code

    Each palette is validated against WCAG contrast before it can ship. These ratios are computed live from the same palettes.

    Contrast ratio against each aura's surface. Floors: body text 7, secondary text 4.5, accent 4.5.

    Motion that matches the mood

    Four tempos, each with its own timing and easing. When a visitor asks for reduced motion, every tempo collapses to a brief fade.

    Build it in four phases

    1. Audit

      Map every page and catalog, and mark where the interface repeats itself.

    2. Foundation

      Ship tokens, auras, the motion system, and the configuration schema with CI checks.

    3. Pilot

      Redesign two contrasting pages end to end. Measure performance and accessibility.

    4. Rollout

      Move remaining pages and catalogs onto the engines, one world at a time.

    One gate before any of it: phases 2 to 4 start only after the current security remediation is verified. Phase 1 is read-only and can begin now.
